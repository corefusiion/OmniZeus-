# Design System - Nuvvy Finance

Este documento descreve a identidade visual e os padrões de interface do projeto Nuvvy Finance.

## 🎨 Paleta de Cores (HSL & HEX)

| Nome | HSL | HEX (Aprox) | Uso |
|------|-----|-------------|-----|
| **Primary** | 160 84% 39% | #10B981 | Botões principais, ícones de destaque, status positivo. |
| **Background** | 210 25% 96% | #F2F5F7 | Fundo principal da aplicação. |
| **Foreground** | 220 20% 10% | #14181F | Texto principal. |
| **Card** | 0 0% 100% | #FFFFFF | Fundo de cards e seções brancas. |
| **Muted** | 210 20% 95% | #F1F3F5 | Fundos secundários, inputs desabilitados. |
| **Border** | 150 20% 90% | #E5E9E7 | Bordas de cards e divisores. |
| **Sidebar BG** | - | #1B1B1B | Fundo da barra lateral. |
| **Sidebar Text** | - | #C5C1B9 | Texto da barra lateral. |

## Typography

- **Fonte Principal:** `Inter`, system-ui, sans-serif.
- **Fonte de Destaque:** `CameraPlainVariable` (usada em títulos e sidebar).
- **Tamanhos:**
  - Base: 16px
  - Sidebar: 12px
  - Títulos: 24px - 32px

## 📐 Espaçamento e Bordas

- **Border Radius:**
  - Geral: `0.625rem` (10px)
  - Cards: `16px`
  - Botões: `12px`
- **Sombras:**
  - Soft: `rgba(0, 0, 0, 0.05) 0px 1px 2px 0px`
  - Card Focus: `rgba(0, 0, 0, 0.25) 0px 25px 50px -12px`

## 📂 Estrutura do Menu

O menu é dividido em seções claras:

1. **PRINCIPAL**
   - Dashboard
   - Despesas
   - Contas Fixas
   - Calendário
   - Metas
   - Relatórios
   - Nuvvy IA
2. **INVESTIMENTOS**
   - Investir
   - Simulador Carteira
   - Minha Carteira
   - Simulador Futuro
3. **GAMIFICAÇÃO**
   - Desafios
   - Conquistas
4. **SOCIAL**
   - Feed
   - Amigos
   - Desafios Sociais
   - Meu Perfil
5. **OUTROS**
   - Configurações

## Icons

- **Biblioteca:** Lucide React.
- **Estilo:** Traços finos (stroke-width: 2), cores variando entre o foreground e o primary green.
